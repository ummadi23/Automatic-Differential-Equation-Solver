About Our Project

The Automatic Differential Equation Solver is a web-based application designed to solve second-order differential equations using the Laplace Transform method.

Project Objective

To simplify the process of solving differential equations by providing step-by-step mathematical calculations, graphical representations and downloadable PDF reports.

Key Features

• Solving second-order differential equations
• Laplace Transform calculations
• Partial Fraction Decomposition
• Inverse Laplace Transform
• Graph visualization
• PDF report download

Technologies Used

Python, Flask, SymPy, NumPy, Matplotlib, HTML, CSS and ReportLab.
